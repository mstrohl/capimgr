# Security Policy

## Supported versions

Security fixes are made against the latest version on the default branch.
Older releases and forks are not guaranteed to receive security updates.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or discussions.
Use GitHub's private vulnerability reporting for this repository. If that
feature is unavailable, contact the repository maintainers privately through
GitHub and include a way to follow up securely.

Include the affected version or commit, the impact, and concise reproduction
details. Avoid attaching real credentials, kubeconfigs, customer data, or
production cluster information. The maintainers will acknowledge the report,
investigate it, and coordinate any fix and disclosure with the reporter.
